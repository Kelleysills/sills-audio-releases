# Sills Audio – releases

Installers and updates for Sills Audio plug-ins (Sills Ultimate Production Suite, Mix Coach, Console Strip, Bus Comp).

- **New computer:** download `SillsAudio-Setup-<version>.exe` from the newest release under **Releases** and run it.
- **Already installed:** Sills Audio Hub updates itself and every plug-in from here automatically.

`revoked.txt` is the signed list of cancelled licence serials. The Hub checks it, and it can't be edited without Sills Audio's signing key.
